# xc881 Solution Research custom instruction

`xc881-solution-research` is intent-routed.

Use it when the user writes:

```text
$xc881-solution-research
```

or clearly asks to research, compare technical options, choose a stack, inspect docs/standards/advisories, verify stale external facts, or judge a technical route.

Do not trigger it from a bare source word such as GitHub, paper, docs, or feasibility without a technical-research decision intent.

When active: normalize rough ideas, derive explicit/inferred research questions, use papers first for principle knowledge, prefer official docs/standards/GitHub/advisories/credible developer sources, compare feasible options compactly, cite sources, hand off, and do not implement code.
