# Handoff

```text
Handoff:
Source:
Target:
Truth:
Scope:
Keep:
Constraints:
Verify:
Open:
```

One skill owns the active phase. Analysis hands off only when the requested next
outcome or a blocking evidence gap requires another skill. A bounded delegate
returns to its owner; diagnosis-only and planning-only work may have no execution
handoff. Coding executes confirmed writes and complex/tracked reads.

Use the full form only when the boundary needs it. A bounded delegate receives
the question/slice, existing evidence, constraints and permissions; it returns
only needed anchors/claims, uncertainty and exact next action. Do not repeat the
owner's whole spec, restart discovery, or reload guidance already in context.
