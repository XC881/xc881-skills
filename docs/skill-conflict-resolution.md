# Skill Conflict Resolution

Select skills from **user intent** AND **actual task readiness/direction**:

- scope/AC/triage, bug/security root cause, or external technical facts -> `xc881-analysis` (Requirement / Bugfix / Solution internal branches; branch switches never delegate);
- ready project edits, complex/tracked reads, reviews, UI, or explicit git -> `xc881-coding-skills` (if scope, cause, or external facts are open on a build/fix request, run `xc881-analysis` first and chain automatically);
- Chinese source-code articles -> `xc881-source-article-style` (chaining Coding for complex source traces and Analysis for external term/version facts);
- cross-language or cross-project migration with behavioral equivalence -> `xc881-porting-orchestration` (chaining Analysis for open boundaries/facts and Coding for edits/parity checks).

One skill owns the active phase. Incidental nouns do not trigger unused skills; ordinary Q&A and simple exact/local/low-risk reads may use no xc881 skill. Multi-phase tasks chain in dependency order rather than running parallel owners.
