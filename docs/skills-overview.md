```text
$xc881-solution-research     question → evidence → fact or options/pick → handoff
$xc881-requirement-analysis  request → ER/IR/AC → handoff
$xc881-bugfix-research       symptom → cause/fix/verify → optional handoff
$xc881-coding-skills         instant/queue → read/change → evidence or patch/verify

```

Implicit routing chooses one primary owner by final outcome. Generic work may use
no xc881 skill; incidental subtasks do not create parallel owners.

Reference routes load only missing guidance for the current concern. Existing
evidence remains reusable when scope/version/freshness fit; bounded delegates
return the exact evidence needed without restarting the owner. Coding includes
the full offline frontend engine/data behind conditional, bounded CLI output.
