# Frontend Visual System And Content

Load only for palette, typography, visual hierarchy, content or media. Continue
the already-loaded frontend routes when another concern arises.

- Preserve semantic tokens. New systems choose coherent palette, radius, border,
  shadow, type, spacing and media framing before local exceptions. Keep supported
  theme hierarchy and contrast intact.
- Prefer readable copy, clear hierarchy, intentional line breaks and concise
  labels to oversized type, micro-label clutter, decorative status marks or
  repeated eyebrows. Do not invent precision, testimonials, customer logos,
  names, metrics or product claims.
- Marketing/editorial work needs a clear first viewport, one primary next action,
  visible contrast, relevant visual media and varied section rhythm; avoid
  mechanically repeating split/equal-card layouts. Product UIs may repeat
  structures when consistent scanning and comparison benefit.
- Use project, supplied, licensed or appropriately generated assets. Div
  rectangles are not product screenshots. An actual live component preview is
  valid; labels over imagery must convey necessary information.
- Keep media aspect ratios, cropping, alternatives and reserved loading space
  stable. Genuine logos require authority; invented social proof is not an asset
  strategy. Missing visual evidence activates the image workflow, not fake media.
