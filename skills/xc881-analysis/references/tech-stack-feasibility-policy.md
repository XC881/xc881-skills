Disqualifier gate first: eliminate options failing license policy, target
runtime/OS/version compatibility, active security/maintenance viability, or hard
resource/dependency limits before comparing soft trade-offs. Then compare
evidenced, decision-relevant fit, complexity, cost, performance, security, ops,
integration, observability, tests, and migration/lock-in cost.

Pin external claims to the exact package/framework version. One viable option
needs no invented rival. Pick when supported; otherwise name the
decision-changing gap and exact next check. Retain residual risk.
