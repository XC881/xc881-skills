# Output

```text
xc881 调研: <一句话主题>
结论:
查证点:
依据:
需要注意:
下一步:
```

`结论` 一句话给查证答案或推荐；`查证点` 分点列要回答的 RQ；`依据` 分点给证据
和来源；`需要注意` 列冲突、过期或残余风险；`下一步` 给请求方的结论去向、
不确定性和精确动作。

只有真实方案决策才附加：

```text
对比:
推荐:
```

事实查证、标准或版本核实不写空的 `对比/推荐`。

服务其他分支时只返回要求的结论/锚点或证据路径，不另起流程。授权实现仍走
Coding。

大调研附加：

```text
记录: <path>
结论数: <count/types>
用途: <支持哪个 RQ/决策>
```

Requirement 分支的证据：

```text
记录: dev-notes/req-process/<task>/evidence/RQ-NNN-<slug>.md
返回: 同一 Requirement run
用途: <RQ / scope / AC / 决策>
下一步: <精确动作或剩余阻塞检查>
```
