# Paper First

Use for algorithms, systems, DB, ML, crypto, consensus, compiler/runtime, security model, performance theory.

Use the original paper for the needed claim; a survey is for locating it, not a
mandatory first read. Read benchmarks/repro code only when applicability or a
performance claim affects the decision. Separate theory from measured behavior;
carry assumptions and limitations into the recommendation.

Output:

```text
Paper:
claim:
why:
limit:
```
