# Rubric

Good: explicit, scoped, testable, traceable, minimal, honest.

Good grilling: one decision at a time; repo facts researched first; user choices separated from agent inference; recommended answer supplied.

Good tracker triage: label transition justified; Agent Brief behavior-oriented; tracker mutations separated as executed/planned/skipped.

Bad: inferred as fact, vague AC, contradictory requirements, hidden dependency, scope creep, many questions, asking for discoverable facts, code before requirement.
