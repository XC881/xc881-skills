# Spec + RQ

Spec:

```text
Goal:
Inputs:
Constraints:
Unknowns:
Output:
```

RQ:

```text
RQ-*:
type: explicit|inferred
why:
search:
```

Infer an RQ only if its answer can change feasibility, the choice, or a binding
constraint. One fact needs one question, not an ecosystem inventory.

Ask one blocking question only if direction changes.
